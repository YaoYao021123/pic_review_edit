为什么做 Lucet 光集

手机上能调，Mac 上却没有顺手的工具。

我用 DJI 拍素材，想调一下颜色和色调，才发现 DJI Mimo 只有手机版（iOS 和 Android，截至 2026 年 10 月）。想在大屏幕上调，只能回到手机上。

Lightroom、Photoshop 当然什么都能做，但打开的第一眼，就是几十个看不懂的滑块。

光集想做中间那一块：在 Mac 上，简单得像手机 App；想学的时候，也有人在旁边讲。
手机里的调色 App

专业软件

功能强大，也意味着第一次打开就要面对几十个参数。

功能

简单开始，需要时再深入

默认只给你最常用的几样。其余的工具都在，只是先收起来。

一键自动

点一下「自动」，先得到一张看得过去的

光集看这张照片本身的明暗和颜色，再替你调好曝光、影调、白平衡和色彩。它很克制：

  • 白底、雪景这类本来就明亮的照片，保持明亮，不会被压灰
  • 夜景保持夜景，日落保留暖色，不会把氛围调没
  • 不满意？按 ⌘Z 撤销，或按 \ 看原图

六个滑块 · 预设缩略图

挑风格，是看出来的，不是试出来的

每个预设都直接用你这张照片预览。点一下就套用，不喜欢就撤销。简单模式只有六个滑块：亮度、对比度、亮部、暗部、冷暖、鲜艳度，每个都配了一句人话解释。

  • AI 调色：一个小型神经网络看过整张照片，为它生成专属的调色；在你的 Mac 上计算，不上传
  • 把你调好的样子存成自己的预设，下次一键用到别的照片上
  • 把一张照片的调色复制给一整批，曝光默认不跟着改

局部调整

只改天空，地面不动

很多照片的问题只在一部分：天空太亮、人物太暗。局部调整把滑块的作用限制在你划出的范围里：

  • 渐变：从一条线逐渐过渡到另一条线，最常用来压暗天空
  • 椭圆：提亮主体，或者反转过来压暗四周
  • 画笔：涂到哪里就调哪里，按住 ⌥ 擦除
  • 主体：自动找出人物、动物和前景物体，反转就调整背景
  • 每一层都有自己的曝光、对比度、高光、阴影、色温、饱和度、清晰度、去雾等；点「显示蒙版」用红色看清范围
  • 范围跟着照片内容走：之后再裁剪、旋转，蒙版也不会错位

一个渐变：天空曝光 −0.7、高光 −45、饱和度 +18，地面完全不变。光集的真实输出。

去除

画面里多了一样东西？涂掉它

用「去除」画笔涂抹电线、路人、垃圾或镜头上的灰尘，松开后光集会在周围找相似的纹理，把它自然地补上。

  • 经典的 PatchMatch 补全，在你的 Mac 上计算，不需要下载模型，也不会上传照片
  • 补好的区域之后照样跟着调色走
  • 适合较小的东西；很大的区域可以分几次去除

拖动裁剪

在照片上直接拖，就像在「照片」App 里一样

打开「构图」，整张照片会显示出来，裁剪框直接在画面上：拖动框移动，拖四个角缩放，画幅比例自动保持。拉直、旋转、镜像也都在这里，地平线歪了还会提醒你。

匹配色调 · 导出 LUT

喜欢哪张的颜色，就让这张向它靠拢

在素材库里选一张你喜欢它色调的照片，光集会把这一张的整体明暗和颜色往它那边带。结果是一个 LUT，可以用强度滑块决定带多少，也可以撤销。

  • 方法是在 Lab 色彩空间里对齐两张照片的平均值和分布（Reinhard 色彩迁移），不会凭空生成内容
  • 反过来，也可以把你调好的颜色导出成 .cube LUT，在 DaVinci Resolve、Final Cut Pro、Premiere 里给视频用

项目

一件事一个项目，一个项目一套颜色

把一次旅行、一篇帖子或一组客片放进同一个项目。在任意一张上调颜色，整个项目都会跟着变；曝光、裁剪和局部调整仍是每张自己的。

  • 「统一明暗与色温」：每张都向整组的中间值靠拢，看起来像同一时间拍的一组
  • 「只这张」：个别照片需要不一样时，单独改它
  • 「导出项目」：已选用的（或全部）照片，存进以项目命名的文件夹
  • 同一张照片可以放进几个项目，每个项目里是各自的版本

重复与相似 · 并排选片

同一个场景拍了好几张？并排看，只留最好的

打开「重复与相似」，光集会把构图和颜色几乎一样的几张、以及同一台相机 2 秒内连续拍下的照片归成一组。点「并排比较」，几张照片并排显示，按 P 选用、X 排除，或者「只保留选中的这张」。

  • 内容完全相同的文件（同一张导入了两次、Finder 里的副本，视频也算）排在最前面，一键排除或移出素材库，硬盘上的文件不会被删除
  • 「放大到 100%」：所有照片同时放大到同一个位置，拖动时一起平移，适合比较谁更清楚
  • 比对在本机进行，几十张照片不到一秒

边调边学

不是教程，而是讲你手上这一张

光集会读这张照片，指出真正的问题：哪里过曝了、哪里偏色、地平线歪了多少度，并给一个可以一键试用的调整。悬停在滑块名上，画面会只高亮它影响的区域。

  • 互动课：几分钟一课，用动画和你自己的照片讲清直方图、曝光、曲线、白平衡、光圈、焦距、视频帧率和 Log，边看边动手
  • 拖动任何一个明暗滑块，直方图都会标出它改变的是哪一段（最暗部到最亮部）
  • 可以选「入门 / 进阶 / 专业」，讲解的深浅会跟着变
  • 想问什么，直接问：「天空为什么发灰？」（可选，需要你自己的 AI 密钥，默认关闭）
  • 学习记录只保存在你的 Mac 上

存进「照片」· Live Photo

调完，一步回到你的 iPhone

导出时默认直接存入 Mac 的「照片」，开启 iCloud 照片后会同步到 iPhone。把一段视频剪成 3 秒以内，还能做成真正的 Live Photo。想要文件也行，或者直接用系统共享发给朋友。

  • JPEG / HEIC / PNG，可缩小到社交平台常用尺寸
  • HDR 照片带增益图导出，调过色也仍是 HDR
  • 导出预设、文件名规则（日期、序号、尺寸），以及可选的文字水印
  • 默认保留拍摄时间、相机信息，移除位置信息
  • 导出在后台进行，你可以接着调下一张
  • 原片从不被修改，导出的永远是一份新副本

还有这些

胶片感、历史记录、按内容找照片

  • 去雾、褪色、颗粒、黑白：在「完整」模式的效果里，去雾用暗通道估计每个区域的雾有多重
  • 历史记录：每一次修改都有名字，点一下就回到那时，关掉再打开也还在
  • 按内容搜索：在素材库输入「天空」「狗」「日落」，画面里有它的照片就会出来，在本机识别

为 DJI 素材准备

拍完就能调，也能看清你的素材

光集能直接打开 DJI 无人机和相机导出的 MP4、MOV。右侧「信息」页会列出编码（如 HEVC Main 10）、位深、码率、帧率、色彩空间和拍摄设备，不用再去别的软件里查。

  • 导入 DJI 官方的 .cube 风格 LUT，已用 Pocket 3 的 Spring / Winter Pro 实测
  • 把在光集里调好的颜色导出成 .cube，带到 DaVinci Resolve 等剪辑软件里继续用
  • 视频可以裁切、变速（0.5–4 倍），也可以截取 3 秒做成 Live Photo
  • 10 位 HEVC 素材正常打开；HDR 视频可预览，高光扩展为实验功能

还在计划中：D-Log 素材自动套用转换 LUT（现在需要你自己导入对应的 LUT）。

怎么做出来的

用一句人话，和 AI 一起把它做出来

光集的第一版，是 ChatGPT 写出来的原型。我把它交给 Claude Code，让它先挑毛病，再一点点改：导入大文件夹不再卡住，界面重做成现在的样子，加上「自动」、预设缩略图和边调边学。你正在看的这个网页，还有宣传视频，也是这样做的：用网页技术写好，再渲染出来。

过程里最有意思的是：几乎每一次改动，都来自一句普通的人话，比如「这个蓝色太亮了」「信息不够」「方框太多」。不用先学编程，把感觉说清楚，剩下的交给 AI 去试、去改、去测试。

AI 也会错，而且错得很像回事。有一张白桌子上的拿铁照片，曾被判成「整体偏亮」，建议把曝光降 1.5 档；可白桌子本来就该亮。这样的问题，都是在真正用的时候一眼看出来，再修好、加上测试的。

也有合作伙伴参与：合作伙伴做的网页版 Lucet（Apache-2.0 开源）里的相似照片分组、色彩匹配和局部蒙版算法，又被移植进了这个 Mac 版。

所以光集也想和你一起做。有想法，到 GitHub 的 Issues 里说；你也在用 Claude Code 或别的 AI 工具做东西，欢迎分享你的做法，互相看看。

三步上手

导入、点自动、存起来

导入

把照片或视频文件夹拖进窗口。同名的照片和视频会自动合成一个 Live Photo。可以打星、选用、排除，先挑出好的。

调色

按 A 自动，再挑一个预设，用六个滑块微调。想看原图，按 \。

存起来

存到「照片」，或共享给朋友。之后再回来，所有调整都还在，也可以随时撤销。

浏览与整理

缩略图网格显示已调色的样子。评级 0–5、选用与排除、按类型和评级筛选、搜索文件名。

完整模式

示波器（直方图、波形、分量、矢量）、色轮、曲线、HSL 色彩混合、风格 LUT，处理顺序固定且每一步都能单独开关对比。

拼图 Live

把多段 3 秒视频拼成一张 Live Photo，每个画面各自调色。

撤销与版本

随时撤销、重做，还可以给一张照片存多个命名版本，随时回到某一个。

适合你，如果

  • 用 DJI 或 iPhone 拍，想在 Mac 上快速调好再分享
  • 觉得 Lightroom、Photoshop 太复杂，只想调亮度、颜色、裁一裁

隐私

你的照片，只在你的 Mac 上

光集没有账号，没有统计，不上传任何照片。唯一会联网的是可选的「问问这张照片」：默认关闭，你填入自己的密钥后，只有在你点「提问」时才会发送一张缩小的预览（可以关掉）和调整参数，不含拍摄地点。

常见问题

你可能想问

会改动我的原片吗？

不会。所有调整都保存成一份很小的配方文件，导出时才生成新的副本。你的原片、原文件名和位置都不会变。如果在 Finder 里移动或重命名了原片，光集会提示「找不到原文件」，指给它新位置就行，调整都会保留。

需要什么电脑？

Apple 芯片（M 系列）的 Mac，系统 macOS 15 或更高。在 macOS 26 上会使用「液态玻璃」界面。

有英文界面吗？

有。光集跟随系统语言显示中文或英文；也可以在菜单栏「Lucet 光集 › Language · 语言」里单独切换。

支持哪些素材？

照片：JPEG、HEIC、PNG、TIFF、WebP、DNG，以及常见相机的 RAW 文件（实验性）。视频：MP4、MOV 等（以 macOS 能解码的为准）。同名的 HEIC/JPG 加 MOV 会自动识别成 Live Photo。

能直接存到 iPhone 吗？

导出时选「保存到 「照片」」，开启 iCloud 照片后，会同步到你的 iPhone。Live Photo 会作为真正的 Live Photo 保存。

打开时提示“无法验证开发者”怎么办？

目前的版本还没有经过 Apple 公证，所以第一次打开会被系统拦下。这是正常的，可以这样放行：

  1. 把「Lucet 光集」拖进「应用程序」，双击打开，看到提示后点「完成」
  2. 打开「系统设置 › 隐私与安全性」，滚动到最下面
  3. 找到「Lucet 光集」，点「仍要打开」，再确认一次

只需要做这一次。你也可以从源码自己构建，见下方「下载」。

「问问这张照片」是什么？

这是可选功能：你可以用自然语言提问，比如「怎么调出胶片感？」，由 Claude 结合这张照片回答，并给出可以一键试用的调整。它需要你自己的 Anthropic API 密钥（保存在 Mac 的钥匙串里），费用由你的账户承担，默认关闭。中国大陆网络可能无法直接访问。不开启它，光集的其他功能完全不受影响。

和 DJI 官方有关系吗？

没有。光集是独立开发的软件，不是 DJI 的产品，也没有得到 DJI 的授权或认可。DJI、Mimo 等名称是各自所有者的商标，这里只用来说明光集可以打开哪些素材。
