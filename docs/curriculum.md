# 光集 互动课 · 课程大纲

目标：让完全没有摄影基础的人，用自己的照片，在几分钟一课的互动动画里搞懂「拍」和「修」的基本原理。

## 教学方法（每一课都遵循）

1. **一个值得回答的问题**：用用户自己的话提出，例如「为什么 ƒ/4 比 ƒ/2.8 的光圈小？」。
2. **把原理画出来**：用动画展示机制（像素→直方图、开口大小→进光量），不靠堆文字。
3. **在自己的照片上动手**：每个演示都用打开的照片和应用真实的渲染管线，拖动即看到结果。需要空间感的原理做成三维场景（可拖动旋转，空闲时缓慢自转，开启「减弱动态效果」时不转）：像素云、镜头、视野楔形、时间纵深、感光格、设置空间、亮度地形等。
4. **回头检验**：一道小题；能用照片本身出题的就用照片出题（例如「这张照片大部分在哪个区域？」）。

统一词汇：五个亮度区「最暗部 · 暗部 · 中间调 · 亮部 · 最亮部」贯穿直方图、滑块提示、曲线和课程。

参考：张小样的抖音视频（6 条，仅作方法参考，内容与画面均为原创，不复制他的脚本或图形）。

### 四、拍摄的原理
| | 课 | 要回答的问题 | 互动方式 |
|---|---|---|---|
| ✅ | 光圈 | ƒ/4 为什么比 ƒ/2.8 小？ | 开口 = 焦距 ÷ ƒ（三维镜头：外圈的光被光圈挡住）；景深 = 空间里一层清楚的薄板，点光源变光斑 |
| ✅ | 快门、ISO、曝光三角 | 为什么有的糊、有的噪点多？ | 快门：时间是纵深，开着的那段是一块玻璃板，球在板里的每个位置都落到同一张照片上；ISO：传感器是一格格计数的格子，光子随机落下，ISO 把数字统统放大，差别变成噪点；三角：三个旋钮是三条轴，亮度正好的所有设置是一块斜板，点在板上就是正确曝光，几种拍法都在板上 |
| ✅ | 焦距与视角 | 广角和长焦差在哪？ | 同一位置换焦距，三维楔形视野 + 照片落在远平面；等效焦距（用照片 EXIF）；透视压缩（俯视，画面宽度对比） |
| 🛠 | 测光与曝光补偿 | 雪景为什么拍成灰的？ | 相机把一切测成中间调 |
| 💡 | 手机的计算摄影 | HDR、夜景模式在做什么？ | 多张合成的动画 |
