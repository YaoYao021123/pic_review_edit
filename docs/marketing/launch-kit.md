## 0. 名字怎么写

- 品牌全称：**Lucet 光集**（英文在前，中间一个空格）。标题、首次出现、图片和视频封面都用全称。
- 正文里第二次以后可以只写「光集」；英文环境写 **Lucet**。
- 口号：**让每一个瞬间，自有光彩。**（英文：Let your moments shine.）
- 名字的来历，一句话版：Lucet 是拉丁语「它在发光」，光集是把光收集起来。
- 「Lucet」怎么读需要你定一个：英文习惯读「卢-塞特」（/ˈluː.sɛt/），古典拉丁语读「卢-凯特」（/ˈluː.kɛt/）。定下来后，视频和口播里统一用一种。

## 1. 先把一句话说清楚

**定位**：给 DJI 和 iPhone 拍摄者的 Mac 调色工具，简单得像手机 App，需要时有完整的专业工具，边调边学。

**起因（真实、可信的那一句）**：DJI Mimo 只有手机版，想在 Mac 上调色没有顺手的选择；Lightroom 和 Photoshop 又太复杂。

一句话备选：

- 在 Mac 上把照片调好看，不用先学摄影。（网站主标题）
- DJI Mimo 只有手机版？光集把调色搬到 Mac 上。
- 一键自动，六个滑块，调完存进「照片」。
- 比 Lightroom 简单，比手机 App 大。

三种长度的介绍：

- **15 字**：Mac 上最简单的照片视频调色。
- **50 字**：Lucet 光集是一款 Mac 调色工具：一键自动、六个滑块、预设一眼挑，DJI 和 iPhone 拍的照片、视频、Live Photo 都能调，调完直接存进「照片」，不用先学摄影。
- **150 字**：我用 DJI 拍素材，想调颜色，才发现 DJI Mimo 只有手机版；Lightroom、Photoshop 又什么都有，却让没有基础的人无从下手。所以做了光集：默认只有「自动」和六个滑块，预设直接用你的照片预览，裁剪直接在画面上拖；想深入就展开示波器、色轮、曲线；它还会指着你这张照片告诉你哪里过曝、哪里偏色。原片从不被修改，所有数据留在你的 Mac 上。

## 2. 谁会在意，去哪找

| 人群 | 他们的痛点 | 去哪里 |
|---|---|---|
| DJI 无人机 / Pocket / Action 用户 | 素材在手机 Mimo 里调，想在 Mac 上调 | 小红书、B 站（DJI 话题）、DJI 论坛和贴吧、各类无人机群 |
| iPhone / Live Photo 爱好者 | 想把视频做成 Live Photo，想统一调色 | 小红书、即刻、少数派 |
| 摄影入门者 | 想学调色，被 Lightroom 吓到 | 小红书、知乎、B 站入门教程评论区 |
| Mac 小工具爱好者 | 找轻量、原生的工具 | 少数派、V2EX（分享创造）、即刻 |

先从最贴近的两类开始：**DJI 用户** 和 **摄影入门者**。起因就是为他们做的，也最容易讲清楚。

## 4. 演示视频（30–45 秒，最值钱的素材）

没有任何一段文字比得上一段屏幕录制。建议用 macOS 自带的录屏（⇧⌘5），在真实的光集窗口里录（这样能看到真实的液态玻璃效果）：

1. 0–3 秒：拖进一个 DJI 素材文件夹。
2. 3–10 秒：点开一张偏灰的照片，按 `A`，再按 `\` 来回对比前后。
3. 10–18 秒：点几个预设，看缩略图和画面的对应。
4. 18–26 秒：切到「构图」，在画面上拖裁剪框，裁成方图。
5. 26–36 秒：打开一段视频，裁成 3 秒，点「制作 Live」。
6. 36–45 秒：导出，选「保存到 照片」，切到「照片」App 里看到结果。

字幕只写一句：**Mac 上最简单的调色。**

## 5. 发布前清单

**必须先做**（不做就别发）：

- [ ] 在你自己的 Mac 上**实际测一遍存到「照片」**：导出一张照片、一段视频、一个 Live Photo，确认出现在「照片」里，iPhone 上也能同步。这是主推功能，目前我没有在你的「照片」资料库里实测过。
- [ ] `bash scripts/package-release.sh`，在 GitHub 新建 Release 上传 zip（版本号在 `scripts/run-workbench.sh` 的 `CFBundleShortVersionString`）。
- [ ] 找一台**没装过开发工具的 Mac**（或新建一个用户账户），按网站上的步骤从下载到打开走一遍，确认「仍要打开」的流程没有写错。
- [ ] 仓库设置 › Pages › Source 选 GitHub Actions，并把分支合并到 `main`，网页才会发布。
- [ ] 给仓库选一个许可证（现在没有 `LICENSE`，法律上默认别人不能使用或修改）。

**强烈建议**：

- [ ] 用真实屏幕截图替换 `website/assets/shot-edit.jpg`，让首屏带上真实的液态玻璃效果。
- [ ] 确认网站和截图里的示例照片、视频你都有权公开。
- [ ] 找 3–5 个**真正没用过的人**试用，看他们第一次打开卡在哪里（见下）。
- [ ] 开 Issues，写一个简短的反馈模板（系统版本、素材来源、截图）。

## 6. 找人试用时，问这些

不要问「好用吗」，要看他们做，并问：

1. 第一次打开，你觉得这是做什么的？（看首屏是否说清楚）
2. 请你把这张照片调好看。（别提示；看他们先点哪里，有没有找到「自动」）
3. 你觉得「亮部」「暗部」是什么意思？（测文案）
4. 调完你会怎么把它放进手机？（看有没有找到「保存到 照片」）
5. 哪一刻你想关掉它？
6. 你愿意把它推荐给谁？为什么？

记录他们**没问出口的卡顿**，比他们说的更有用。

## 7. 说话要注意

- **别说「DJI 在 Mac 上没有软件」**。DJI Studio 有 Mac 版（用于 360° 素材）；准确的说法是 **DJI Mimo 只有手机版（iOS / Android）**。
- 不要暗示和 DJI、Apple、Adobe 有合作或认可；网站页脚已经有声明。
- 不要拿 Lightroom、Photoshop 来贬低；说「对没有基础的人太重」就够了。
- 不要写没做到的：D-Log 自动识别、英文界面、Intel Mac、RAW 冲洗，目前都没有。
- 价格：目前没有定价，网站和 README 都不提价格。对外也不要主动承诺「免费」或「收费」；以后如果有变化，先改网站和 README，再对外说。
